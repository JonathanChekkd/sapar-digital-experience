Use case: ui-mockup
Asset type: high-fidelity north-star mobile app screen, 390 x 844 portrait
Primary request: Design a complete first-screen mobile UI for SAPAR, an original adult Brazilian Jiu-Jitsu social competition platform. Direction name: Mat Atlas Leaguehouse. The user lands on PULSE, a living league map that connects fictional adult athletes, gyms, competitions, and verified results. This is a shippable interface mockup, not concept art and not a poster.
Structure: safe-area header with an original compact SAPAR wordmark and synthetic-data status; a horizontal row of compact community or story beacons; one dominant illustrated Match Path panel occupying about 35 percent of the screen, showing an original stylized adult grappler and a small connected route between gym, event, result, and rating explanation; below it a clean social activity item and a next-training strip; persistent five-item bottom navigation labeled PULSE, COMPETE, CREATE, DISCOVER, PROFILE with an emphasized central CREATE control.
Visual world: optimistic full palette with electric cobalt, fresh court green, warm coral, amber, cream, and charcoal ink. Original polished stylized 3D/cartoon adult athletes, expressive but respectful, no childish proportions. Tactile illuminated controls inspired by premium arcade hardware, with physical depth and clear press surfaces but no gambling cues. Selective glass only where it overlays artwork. Rounded structural panels 12-16px, compact pills only for status. Crisp Lucide-like line icons.
Type and hierarchy: highly legible geometric grotesque UI type, large flush-left title, fixed mobile UI scale, tabular numerals. Exact visible text should be minimal and include: "PULSE", "Your mat, in motion.", "Synthetic demo", "Open Mat League", "Verified result", "Why +22", "Tonight 6:30", and bottom labels "Pulse", "Compete", "Create", "Discover", "Profile".
Motion implication: the route path feels ready to expand when touched; earned verified node glows once, everything else is calm.
Accessibility: WCAG-like contrast, 44px controls, no critical meaning by color alone, clear focus/pressed affordances.
Constraints: original design only; no Instagram, Clash, chess.com, Jits.gg, UFC, casino, slot machine, or other brand trade dress; no copied characters, card frames, maps, layouts, icons, wording, logos, ratings, or athlete likenesses; no blood, injury, minors, belts inferred from ratings, fake scarcity, loot boxes, random rewards, streak loss, or medical claims; no watermark; no device mockup; render one straight-on full mobile screen with practical UI and readable hierarchy.
